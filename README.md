## מה זה סקיל?
סקיל הוא נוהל עבודה שכותבים ל-AI פעם אחת. אחרי שמתקינים אותו, מספיק לבקש, ו-Claude עושה את המשימה בדיוק לפי הנוהל, בכל פעם ובאותה רמה.

## הורדה
לוחצים על הכפתור הירוק **Code** למעלה ← **Download ZIP**, ופותחים את הקובץ במחשב.

## התקנה

### אפשרות א': באפליקציית Claude (claude.ai, Claude Desktop, Cowork)
1. בתיקייה [`zip`](zip) יש קובץ zip לכל סקיל.
2. ב-Claude נכנסים ל**הגדרות** (Settings) ומחפשים את אזור ה-**Skills**. בדרך כלל הוא נמצא תחת Capabilities.
3. מוודאים שהאפשרות להרצת קוד ויצירת קבצים (Code execution and file creation) מופעלת.
4. לוחצים **Upload skill** ובוחרים את קובץ ה-zip. חוזרים על זה לכל סקיל שרוצים.

שמות התפריטים עשויים להשתנות מעט בין גרסאות.

### אפשרות ב': ב-Claude Code
מעתיקים את תיקיית הסקיל, מתוך [`skills`](skills), לתיקיית הסקילים האישית:
- **Windows:** `%USERPROFILE%\.claude\skills\`
- **Mac:** `~/.claude/skills/`

למשל `C:\Users\<השם שלכם>\.claude\skills\cfo-analyst\SKILL.md`. אחרי ההעתקה פותחים סשן חדש.

### איך יודעים שזה עובד?
מבקשים משהו במילים רגילות, לפי העמודה "איך מבקשים" למעלה. Claude מזהה לבד מתי הסקיל רלוונטי. אפשר גם לבקש במפורש: "תשתמש בסקיל cfo-analyst".

## שלושה כללים לעבודה בטוחה
1. **אתם החותמים.** הסקיל עושה את העבודה, אבל בודקים כל תוצאה לפני שהיא יוצאת החוצה. במיוחד מספרים.
2. **מידע רגיש:** לפני שמעלים קובץ עם שמות לקוחות, תעודות זהות או שכר, מסתירים את הפרטים המזהים. בארגון, עובדים עם רישיון ארגוני.
3. **סקילים ממקורות אחרים:** סקיל יכול להריץ פעולות על המחשב. מתקינים רק ממקור שסומכים עליו, ואחרי שקראתם את `SKILL.md`.

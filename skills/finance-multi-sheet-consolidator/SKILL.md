# איחוד וניקוי גיליונות כספיים

## מתי להשתמש
כשחוברת אקסל מכילה מספר גיליונות תנועות כספיות עם עמודות כמו תאריך, מספר מסמך, ספק, קטגוריה, סכום, מחלקה, מטבע, סטטוס — והמשתמש מבקש לנקות, לסדר, לאחד או לסכם אותם.

## מטרה
להפוך את החוברת לדאטהסט אחד נקי ובר-ביקורת + גיליון סיכום ניהולי.

## כלל ברזל
אין לשנות, למחוק או לעצב מחדש את גיליונות המקור. כל הפלט נכתב לגיליונות חדשים בלבד.

## שלבים

### 1. זיהוי מקורות
סרוק את כל הגיליונות. כלול גיליון אם יש בו לפחות 5 מהעמודות: תאריך, מספר מסמך, ספק, קטגוריה, סכום, מחלקה, מטבע, סטטוס.
דלג על "נתונים_מאוחדים" ו"סיכום" (פלטים של ריצה קודמת).
עמודה נוספת שלא ברשימה — שמור אותה, אל תיכשל בגללה.
Done when: רשימת גיליונות המקור ומספר השורות בכל אחד ידועים.

### 2. ניקוי שורה-שורה
- הסר שורות ריקות לחלוטין.
- טקסט: trim, הסרת תווים בלתי נראים, צמצום רווחים כפולים לרווח אחד.
- תאריכים: המר כל פורמט לתאריך אקסל אמיתי (סריאלי) עם numberFormat "dd/mm/yyyy". טפל ב: dd/mm/yyyy, yyyy-mm-dd, d.m.yy, dd-mm-yyyy, yyyy/mm/dd, מספר סידורי קיים. שנה דו-ספרתית → 20xx.
- סכומים: הסר ₪ / "שח" / רווחים / פסיקי אלפים. ערך בסוגריים = שלילי. התוצאה מספר אמיתי.
- מטבע: ₪, שח, שקל, ILS → "ILS".
Done when: אין ערך טקסטואלי בעמודות תאריך וסכום.

### 3. הסרת כפילויות
מפתח עסקי = מספר מסמך + תאריך + סכום. שמור את המופע הראשון.
Done when: מספר הכפילויות שהוסרו מדווח למשתמש עם מספרי המסמך.

### 4. גיליון "נתונים_מאוחדים"
- מחק וצור מחדש אם קיים.
- עמודות: התקניות + "גיליון מקור" (שם הגיליון) + "חודש" (נוסחה `=DATE(YEAR(תאריך),MONTH(תאריך),1)`, פורמט mm/yyyy).
- מיין לפי תאריך עולה.
- הפוך ל-Excel Table בשם `tbl_Merged`, סגנון TableStyleMedium2, הקפא שורת כותרת, autofit.
- פורמט סכום: `₪#,##0.00;(₪#,##0.00);-`
Done when: הטבלה קיימת, ממוינת, ומספר השורות = סך שורות המקור פחות ריקות פחות כפילויות.

### 5. גיליון "סיכום"
כל המספרים בנוסחאות מובנות (structured references) על `tbl_Merged` — לעולם לא ערכים מוקשחים.
- KPI: `=SUM(tbl_Merged[סכום])`, `=COUNTA(tbl_Merged[מספר מסמך])`, ספקים ייחודיים `=SUMPRODUCT(1/COUNTIF(tbl_Merged[ספק],tbl_Merged[ספק]))`, ממוצע לתנועה, טווח תאריכים MIN/MAX.
- בלוקים (כל אחד: סכום / תנועות / % מסה"כ + שורת סה"כ): לפי מחלקה, לפי קטגוריה, לפי סטטוס, לפי גיליון מקור, דירוג ספקים.
- נוסחאות: `=SUMIF(tbl_Merged[שדה],$A{שורה},tbl_Merged[סכום])` ו-`=COUNTIF(...)`.
- עיצוב: כותרות ברקע #146C5A וטקסט לבן, שורות סה"כ ברקע #E6F2EF ומודגשות.
Done when: סך כל בלוק שווה ל-KPI סה"כ סכום.

### 6. אימות לפני דיווח
קרא בחזרה את שני הגיליונות ובדוק:
- אין #VALUE!/#REF!/#NAME?
- עמודת תאריך מוצגת כתאריך, עמודת סכום כמספר
- סך המחלקות = סך הקטגוריות = סך הסטטוסים = KPI סה"כ
- גיליונות המקור ללא שינוי

### 7. דיווח
דווח בקצרה: כמה שורות נוקו, אילו פורמטי תאריך תוקנו, אילו כפילויות הוסרו (עם מספרי מסמך), כמה שורות ריקות ירדו, וכל ערך חשוד שלא תוקן אוטומטית (למשל שם ספק עם שגיאת כתיב) — דגל אותו למשתמש במקום לתקן על דעת עצמך.
